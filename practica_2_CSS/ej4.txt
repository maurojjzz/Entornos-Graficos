Ejercicio 4
Dadas las siguientes declaraciones:

* {color:green; }

a:link {color:gray }

a:visited{color:blue }

a:hover {color:fuchsia }

a:active {color:red }

p {font-family: arial,helvetica;font-size: 10px;color:black; }

.contenido{font-size: 14px;font-weight: bold; }


Analizar los siguientes códigos y comparar sus efectos. Explicar:

1)

<body>
    <p class="contenido" style="font-weight: normal;">
        Este es un texto ...............
    </p>

    <table>
        <tr>
            td>Y esta es una tabla.......</td>
        </tr>
        <tr>
            <td>
                <a href="http://www.google.com.ar">con un enlace</a>
            </td>
        </tr>
    </table>
</body>

    El color de las letras sera verde solo en la primer fila de la tabla, el link que hay en la tabla que sera gris por defecto, fucsia cuando el cursor se posicione sobre el , azul si ya se ha visitado el sitio. El texto contenido en la etiqueta <p> tiene estilo Arial, tamaño de 10px y color negro

2) 

<body class="contenido">
    <p> Este es un texto................</p>
    <table>
        <tr>
            <td>Y esta es una tabla.......</td>
        </tr>
        <tr>
            <td>
                <a href="http://www.google.com.ar">con un enlace</a>
            </td>
        </tr>
    </table>
</body>

El tamaño de las letras sera de 14px y negrita debido a la clase .contenido del body a excepcion del <p> que ya tiene su preset que la fuente arial, tamaño 10px y letra color negra. El link que hay en la tabla que sera gris por defecto, fucsia cuando el cursor se posicione sobre el , azul si ya se ha visitado el sitio.
